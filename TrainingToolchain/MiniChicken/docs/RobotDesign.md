# MiniChicken 双足机器人关节设计文档

基于 Unity 物理系统（PhysX ArticulationBody）的双足机器人强化学习训练工程。

## 1. 总体构型

- **类型**：刚性浮动基座双足机器人（无手臂，聚焦腿部运动控制）
- **自由度**：10 个主动旋转关节（每腿 5 个）
- **总质量**：约 29.8 kg
- **总身高**：约 1.39 m（站立髋高 1.14 m）
- **朝向约定**：机器人面向 **+Z**（Unity forward），+X 为左侧
- **驱动方式**：每个关节为 PhysX `ArticulationDrive` 内置 PD 控制器（位置目标模式），带力矩上限与关节限位

```
                 ┌─────────────┐
                 │   Pelvis    │  浮动基座 12 kg (0.32×0.50×0.24 m)
                 └──┬───────┬──┘
              L_HipYaw   R_HipYaw     ← 髋偏航 (Y轴)
                    │       │
                 L_HipRoll  R_HipRoll   ← 髋侧摆 (Z轴)
                    │       │
                L_HipPitch  R_HipPitch  ← 髋俯仰 (X轴) 大腿 0.36 m, 3.2 kg
                    │       │
                  L_Knee    R_Knee      ← 膝俯仰 (X轴) 小腿 0.36 m, 2.4 kg
                    │       │
              L_AnklePitch R_AnklePitch ← 踝俯仰 (X轴) 脚掌 0.20×0.09 m, 1.3 kg
                 ▔▔▔▔     ▔▔▔▔
```

构型说明：脚掌直接挂在踝俯仰段上（无踝侧摆关节），与 Unitree A1/Go2 式腿部方案一致；侧向平衡完全由 HipRoll 承担。

## 3. 关节规格（左腿；右腿轴按矢状面镜像）

| # | 关节 | 旋转轴 | 限位 (°) | 静息角 (°) | Kp | Kd | 力矩上限 (N·m) |
|---|---|---|---|---|---|---|---|
| 0/5 | HipYaw | ±Y | ±30 | 0 | 120 | 4.0 | 60 |
| 1/6 | HipRoll | ±Z | ±35 | 0 | 150 | 6.0 | 90 |
| 2/7 | HipPitch | +X | -60 ~ +90 | 0 | 180 | 8.0 | 120 |
| 3/8 | Knee | +X | +5 ~ +120 | +10 | 180 | 8.0 | 120 |
| 4/9 | AnklePitch | +X | ±50 | -10 | 60 | 2.0 | 40 |

**符号约定**（+Z 为前）：
- 绕 +X 正角 = 肢体末端向后摆；Knee 正角 = 屈膝（小腿向后），静息 10°
- AnklePitch 静息 -10° 补偿屈膝，保证脚掌水平贴地
- **镜像规则**：右腿的 Y/Z 轴分量取反（yaw/roll 对称运动方向相反），X 轴（pitch）不变 —— 使对称动作在左右腿上具有相同的正方向语义，利于策略学习

**动作映射**：`target(°) = rest + Rad2Deg(0.5 rad × action ∈ [-1,1])`，再夹紧到限位范围（ActionScale 单位为弧度，±0.5 rad ≈ ±28.6°）。

## 4. 强化学习任务定义（速度指令跟随行走）

### 观测空间（40 维，1 帧堆叠）

| 观测 | 维数 | 说明 |
|---|---|---|
| 躯干角速度（局部系） | 3 | angularVelocity / 5 |
| 投影重力方向 | 3 | body 系下的世界 -Y |
| 关节角度（归一化） | 10 | 按 [min,max] 线性映射到 [-1,1] |
| 关节角速度 | 10 | jointVelocity / 720 (deg/s) |
| 双脚触地标志 | 2 | 脚底 raycast，离地 < 2 cm 判接触 |
| 速度指令 | 3 | (vx, vz, ωyaw)，除以 2 归一 |
| 上一步动作 | 10 | |

### 动作空间（10 维连续 [-1,1]）
10 个关节的目标角度偏移（PD 位置目标）。

### 奖励函数（按秒计，×dt 累积）

| 项 | 权重 | 公式 |
|---|---|---|
| 线速度跟踪 | 1.2 | `exp(-1.5·‖v_xy − v_cmd‖²)` |
| 偏航跟踪 | 0.25 | `exp(-1.0·(ωy − ω_cmd)²)` |
| 朝向对齐 | 0.2 | `0.5·(1 + forward·v̂_cmd)`，指令近零时不算 |
| 直立 | 0.3 | `max(0, up·up_world)` |
| 身高维持 | 0.2 | `exp(-8·(h − 1.14)²)` |
| 存活 | 0.1 | 常数 |
| 动作平滑惩罚 | -0.05 | `mean((a_t − a_{t−1})²)` |
| 动作幅度惩罚 | -0.005 | `mean(a²)` |

**终止条件**：躯干高度 < 0.75 m、或 up·world_up < 0.3（摔倒）、或达到 MaxStep（600 决策 = 60 s）。

### 课程学习（内置）
前 2000 个 episode 内速度指令范围从 ±0.5 m/s 线性扩大到 ±2.0 m/s，偏航指令从 0 扩大到 ±1 rad/s。

### 域随机化（sim-to-real，`LocomotionAgent.domainRandomization`）

实物装配存在质量/重心/摩擦/驱动参数误差（如 ≤500 g 电池的前后安装偏移），训练时每回合随机化这些参数，让真实偏差成为策略"见过的样本"：

| 项 | 默认范围 | 实现方式 |
|---|---|---|
| 整机质量 | ±15% | 各 ArticulationBody.mass 缩放 |
| 电池配重 | 0~0.5 kg，前后 ±4 cm | 安装点持续施加等效重力 m·g（复现重心偏移的重力矩） |
| 脚底摩擦 | 0.5~1.2 | 实例化 PhysicMaterial |
| PD 增益 | ±10% | xDrive 刚度/阻尼缩放 |
| 推力扰动 | 5~15 N·s，0.2 次/s | 随机水平冲量 AddForceAtPosition |

随机参数**不进入观测**（部署时不可知）；配合循环网络（LSTM，`use_recurrent: true`）从观测历史在线隐式估计真实动力学（RMA 近似），实现自适应。验证场景可用 `BatteryOffsetTester`（按键 `[ / ]`、`- / =`）实测策略可容忍的电池偏移范围，指导结构件的电池安装位公差设计。

### 训练超参
ML-Agents PPO：网络 512×3 + LSTM 256（循环），normalize=true，batch 4096，lr 3e-4，详见 `training/biped_locomotion.yaml`。

## 5. 物理设置

- Fixed Timestep：0.02 s（50 Hz）
- 决策周期：5 物理步（10 Hz 控制频率，接近真实机器人）
- 相邻连杆间忽略碰撞；非相邻连杆（如脚与躯干）保持碰撞
- 每回合重建机器人保证干净的初始状态（消除浮点误差累积）
