工作模式（MOD）

扭矩（ULK / ULR）

释放扭矩后舵机掉电，可用手扳动输出轴（用于调整机械装配）。

暂停 / 继续 / 停止（DPT / DCT / DST）

暂停：挂起当前指令剩余时间；继续：恢复剩余时间；停止：立即停在当前位置，之后无法继续。

中值与上电初始位置（SCK / CSD / CSM / CSR）

SCK：把「当前位置」设为 1500 中值（用于机械零位校准）。SCK±偏移：把 1500±偏移 作为新的中值。CSD：把「当前位置」设为上电初始位置（无参数，先移动到位再发）。CSM：清除初始值；CSR：恢复初始值。

释力与 RGB 指示灯（官方例程扩展指令）

PULM：释力且不带阻力（输出轴完全自由）；PLN / PLF：RGB 指示灯开 / 关。

通信波特率（PBD）

修改后需要把本窗口波特率切到同一档并重新连接，否则通信会失败。

恢复出厂（CLE0 / CLE）

CLE0：保留 ID，其余参数恢复默认；CLE：全部恢复默认（ID 也变回 000）。
